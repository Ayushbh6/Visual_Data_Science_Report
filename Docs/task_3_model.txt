  Answer text Question 1
  I implemented a PCA + KMeans clustering approach to group countries into a small number of
  similar structural profiles using their 2019 indicators (GDP, health spending, internet use,
  air passengers, population, etc.), and then compared how these profiles differed in the 2020
  tourism shock (shock_2020). I preprocessed the indicators with median imputation for missing
  values, applied log transforms to heavily skewed variables (e.g., GDP), and standardised all
  features so variables are comparable. PCA reduced the 10 indicators to two dimensions
  capturing approx 64.5% of the variation, and I selected the number of clusters using
  silhouette score over k =2–5, which chose k = 4. The resulting clusters show differences in
  shock severity: one cluster had a smaller mean drop (−61.7%) while the others were closer to
  the global collapse range (approx −71% to −73%).
